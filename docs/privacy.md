# Privacy Policy

LeetCode Shorts is a personal tool used only by its owner.

- **What it does:** it uploads videos to my own YouTube channel, and to no other channel or account.
- **Data collection:** it collects no data from anyone. It does not track visitors, use cookies or analytics, or read, store or share any information about other YouTube users.
- **Credentials:** the only credential it holds is the OAuth token for my own YouTube channel, which is stored as an encrypted GitHub Actions secret and is never committed to the repository or shared.

If you have questions about this policy, open an issue on the [GitHub repository](https://github.com/markdickson24/leetcode-shorts).
